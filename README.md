# SpendWise Dashboard

## 📌 Project Overview

SpendWise Dashboard is a responsive financial dashboard shell created using **HTML and CSS**.

The project provides a clean visual interface for managing and viewing different categories of personal financial information. It focuses on modern CSS layout techniques such as **CSS Grid, Flexbox, CSS custom properties, responsive design, and micro-interactions**.

> Note: This project is a visual dashboard only. It does not include JavaScript functionality or data storage.

## ✨ Features

* Responsive dashboard layout
* Sidebar navigation menu
* Dashboard header
* Six financial category cards
* Food expenses
* Transport expenses
* Rent expenses
* Entertainment expenses
* Savings information
* Utilities information
* CSS Grid for the main layout
* Flexbox for internal layouts
* CSS custom properties for the color theme
* Hover and keyboard focus effects
* Responsive design for smaller screens
* Dark theme using `prefers-color-scheme`

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Grid
* Flexbox
* CSS Custom Properties
* Google Fonts
* Responsive Media Queries

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code**.
3. Open `index.html`.
4. Open the file in a web browser.
5. Resize the browser window to test the responsive layout.

You can also use the **VS Code Live Server extension** to launch the project.

## 📱 Responsive Design

The dashboard is designed to work on different screen sizes.

Below **768px**, the dashboard changes to a single-column layout to improve usability on smaller screens.

The responsive layout can be tested using:

**Browser DevTools → Device Toolbar**

## 🎨 Theme

The project uses CSS custom properties to define the main theme colors.

Examples include:

* Brand color
* Accent color
* Background color
* Surface color
* Primary text color
* Secondary text color

A dark theme is also supported using the user's system color preference.

## 🖱️ Micro-interactions

Dashboard cards include subtle hover and keyboard focus effects.

The effects use:

* `transform`
* `box-shadow`
* `transition`

The animation duration is **250ms**, keeping the interaction quick and smooth.

## 🎯 Project Goal

The goal of this project is to demonstrate how modern CSS layout techniques can be used to create a clean, responsive dashboard interface.

This dashboard will serve as the foundation for the **SpendWise capstone project**, where additional functionality can be added later.
